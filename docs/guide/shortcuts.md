# Shortcuts

On Windows and Linux, use **Ctrl** wherever this page says **⌘**.

## Control window

| Keys | Action |
|---|---|
| **⌘S** | Save the workspace. Works from anywhere in the window. |
| **⌘Z** | Undo a structural change (adding, removing, moving, or reordering a layer or effect). |
| **⇧⌘Z** | Redo. |
| **⌘T** | **TAKE**: crossfade to the other deck over the TAKE time. |
| **Esc** | Leave focus mode (library and inspector hidden), or close the About box. |
| **⌘-click** or **Shift-click** a layer | Add it to the pick, to make a group. |
| **Enter** | Confirm a name you're typing (deck, chain, layer). |

Parameter changes aren't undoable, because they're continuous and MIDI,
LFOs, and OSC move them all the time.

## Projector windows

| Keys | Action |
|---|---|
| **Shift+F** | Toggle fullscreen. |
| **Esc** | Leave fullscreen. |

**Esc** only ever *leaves* fullscreen. It never closes an output, so a stray
key press mid-show can't black out the room.
