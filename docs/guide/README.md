# KOVVBOJ guide

This guide is for people performing with KOVVBOJ. If you want to work on the
code, read [CONTRIBUTING](../../CONTRIBUTING.md) and the
[architecture notes](../architecture.md) instead.

1. [Getting started](getting-started.md): install the app, get to know the
   window, and build a first set.
2. [Decks and layers](decks-and-layers.md): the two decks, layers, blend modes,
   and TAKE.
3. [Effects](effects.md): the shader library, effect chains, transitions, and
   adding your own ISF shaders.
4. [Modulation](modulation.md): LFOs, audio, and tempo sync, plus MIDI and LFO
   map modes.
5. [Outputs](outputs.md): projectors, the stage, corner-pin and edge blend,
   NDI, Syphon, and Spout, and recording.
6. [Lighting](lighting.md): LED strips over sACN and Art-Net, and calibration.
7. [Lasers](lasers.md): laser decks. This feature is experimental.
8. [Control](control.md): OSC, MIDI, and the web API.
9. [Shortcuts](shortcuts.md): keyboard shortcuts.
10. [Performance](performance.md): codecs, HAP, and what to do when things
    slow down.
